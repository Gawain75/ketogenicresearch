# Fully automatic literature curation

The daily workflow is fully automatic.

It:
1. finds recent PubMed papers directly relevant to ketogenic research;
2. assigns up to three existing clinical areas;
3. classifies the evidence type;
4. checks whether the title is already present in the Curated Library;
5. automatically promotes new records when at least one existing clinical area is supported with sufficient rule confidence;
6. updates the Curated Library counters automatically.

Low-confidence or uncategorizable records remain in `review-queue.json` with
`curation_status: "excluded-low-confidence"` and are not inserted into the Library.

No manual PMID approval is required.

`latest-publications.json` and `review-queue.json` are generated by GitHub Actions and are intentionally not bundled in release archives.
