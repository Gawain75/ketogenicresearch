# Automated curation pipeline

The daily workflow now performs four tasks:

1. Finds recent PubMed publications relevant to ketogenic research.
2. Assigns one or more clinical areas from the existing site taxonomy.
3. Classifies the evidence type and writes non-curated candidates to `review-queue.json`.
4. Promotes only explicitly approved PMIDs into the Curated Scientific Library.

## Approval

Edit `curation-decisions.json`.

Example:

{
  "approved_pmids": ["12345678", "23456789"],
  "rejected_pmids": ["34567890"],
  "area_overrides": {
    "12345678": ["Epilepsy", "Neurology & Neuroscience"]
  }
}

Only area names that exist as clinical sections in `library.html` can be promoted.

`review-queue.json` is generated by the workflow and should not be edited as the source of truth.
Use `curation-decisions.json` for approval/rejection and category overrides.

This keeps Latest Evidence automatic while preserving human control over the Curated Library.
