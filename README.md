# Ketogenic Research

Bilingual (EN/IT) static website for ketogenicresearch.org.

## Included
- Responsive single-page institutional site
- Custom SVG logo
- EN/IT language switch with localStorage
- Marco Medeot portrait sourced from Wikimedia Commons
- Research areas, scientific direction, selected work and contact sections

## Publish on GitHub Pages
1. Create a public repository and upload `index.html` + `styles.css`.
2. Enable Settings → Pages → Deploy from branch → main → root.
3. Set the custom domain to `ketogenicresearch.org`.
4. Configure the DNS records at your domain registrar as shown by GitHub.
